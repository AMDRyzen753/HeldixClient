# Hinweise zur nächsten Version
# Jede Zeile mit "- " erscheint im Launcher unter „Was ist neu“ und im Versionsverlauf auf heldixclient.com.
# Vor jedem "npm run release" anpassen. Zeilen mit # werden ignoriert.

- Neu: Addon-Store – Addons wie Spotify oder Uhrzeit & Spielzeit einzeln installieren und aktualisieren: im Launcher (Instanz → Heldix-Addons), im Spiel (Heldix-Menü → Addons → Addon-Store) und auf heldixclient.com/addons
- Neu: Jedes Addon im Store ist vom Team signiert; Launcher und Spiel prüfen Signatur und Prüfsumme vor dem Installieren
- Neu: „Addons“ hat im Heldix-Menü einen eigenen Eintrag in der Seitenleiste, mit Abzeichen, wenn ein Update bereitsteht
- Geändert: Der Launcher bringt keine Addons mehr mit – schon installierte bleiben erhalten
