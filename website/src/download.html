Installation

Schritt für Schritt

  1. Installer laden und starten. Die Datei heißt HeldixClient-Setup-…exe.
  2. Windows SmartScreen: Erscheint „Der Computer wurde durch Windows geschützt“, klick auf „Weitere Informationen“ und dann auf „Trotzdem ausführen“. Der Installer hat noch keine kostenpflichtige Signatur.
  3. Anmelden mit dem Microsoft-Konto, mit dem du Minecraft gekauft hast.
  4. Spielen drücken. Minecraft und Java lädt der Launcher selbst. Später aktualisiert er sich von allein.
  1. Disk-Image laden und öffnen (Apple Silicon oder Intel, siehe oben).
  2. HeldixClient in „Programme“ ziehen und von dort starten.
  3. macOS blockiert den ersten Start: Öffne Systemeinstellungen → Datenschutz & Sicherheit und klick unten auf „Dennoch öffnen“. Die App ist nicht von Apple beglaubigt.
  4. Anmelden und spielen wie unter Windows. Neue Versionen meldet der Launcher; du lädst sie dann hier.

Ist der Download sicher?{{icon:chevron-down}}

Alle Dateien kommen von unserem eigenen Server. Die SHA-256-Prüfsumme oben zeigt, ob deine Datei unverändert ist. Unter Windows prüft der Launcher jedes Update zusätzlich mit einer digitalen Signatur.

Warum warnt mein System?{{icon:chevron-down}}

Die Dateien haben noch keine kostenpflichtige Signatur von Microsoft oder Apple. Deshalb fragt dein System beim ersten Start einmal nach – siehe Anleitung oben.

Wie bekomme ich Updates?{{icon:chevron-down}}

Unter Windows aktualisiert sich der Launcher selbst. Auf dem Mac meldet er neue Versionen; du lädst sie dann auf dieser Seite.

Gibt es HeldixClient für Linux oder das Handy?{{icon:chevron-down}}

Zurzeit nicht – nur für Windows und Mac.

Es klappt nicht – was nun?{{icon:chevron-down}}

Im Hilfe-Center stehen Lösungen für typische Probleme. Sonst schreib dem Team über eine Support-Anfrage.
