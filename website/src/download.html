{{icon:play}}Installation

Schritt für Schritt

So kommst du vom Download bis ins Spiel. Die Einrichtung beim ersten Start ist auf Windows und Mac gleich.

Windows

  1. Installer laden und starten

    Die Datei heißt HeldixClient-Setup-{{VERSION}}.exe. Der Installer im HeldixClient-Design fragt nach dem Ordner und startet HeldixClient am Ende.

    Erscheint „Der Computer wurde durch Windows geschützt“, klick auf „Weitere Informationen“ und dann auf „Trotzdem ausführen“ – der Installer hat noch keine kostenpflichtige Signatur.

  2. Mit Microsoft anmelden

    Die Einrichtung beim ersten Start fragt nach deinem Microsoft-Konto – dem, mit dem du Minecraft: Java Edition gekauft hast. Dein Passwort gibst du nur im Fenster von Microsoft ein.

  3. Addons aussuchen

    Offizielle Addons wie Voice Chat, Minimap und Uhrzeit & Spielzeit sind vorausgewählt – geprüft und signiert vom Team. Ändern kannst du alles später im Addon-Store.

  4. Spielen

    „Spielen“ drücken – Minecraft und Java lädt der Launcher selbst. Hat dich jemand eingeladen, nimmst du die Einladung am Ende der Einrichtung an. Updates installiert der Launcher beim Start von allein.

    {{icon:friends}}Tipp: Deinen eigenen Einladungs-Link findest du im Launcher unter Freunde → Einladen.

Mac

  1. Disk-Image laden und öffnen

    Für Apple Silicon (M1 und neuer) oder Intel – welche Datei passt, steht unten. HeldixClient in „Programme“ ziehen und von dort starten.

    {{icon:info}}Welcher Mac? Unter Apple-Menü → „Über diesen Mac“ steht bei Apple Silicon „Chip“ (M1, M2 …), bei Intel „Prozessor“.

  2. Ersten Start erlauben

    macOS blockiert den ersten Start, weil die App nicht von Apple beglaubigt ist: Öffne Systemeinstellungen → Datenschutz & Sicherheit und klick unten auf „Dennoch öffnen“.

    {{icon:help-circle}}Hilfe: Mac blockiert die App – mit allen Schritten.

  3. Einrichten und anmelden

    Die Einrichtung führt dich durch Microsoft-Anmeldung, empfohlene Addons und – falls vorhanden – deine Einladung.

  4. Spielen und auf dem Laufenden bleiben

    „Spielen“ drücken – Minecraft und Java lädt der Launcher selbst. Neue Versionen meldet der Launcher; du lädst sie dann hier.

Ist der Download sicher?{{icon:chevron-down}}

Alle Dateien kommen von unserem eigenen Server. Die SHA-256-Prüfsumme oben zeigt, ob deine Datei unverändert ist. Jedes Update prüft der Launcher zusätzlich mit einer digitalen Signatur des Teams.

Warum warnt mein System?{{icon:chevron-down}}

Die Dateien haben noch keine kostenpflichtige Signatur von Microsoft oder Apple. Deshalb fragt dein System beim ersten Start einmal nach – siehe Anleitung oben.

Wie bekomme ich Updates?{{icon:chevron-down}}

Der Launcher installiert Updates beim Start von selbst – unter Windows und ab Version 0.14.0 auch auf dem Mac, wenn HeldixClient im Ordner Programme liegt. Ältere Mac-Versionen lädst du einmal neu von dieser Seite. Was neu ist, steht im Versionsverlauf.

Gibt es HeldixClient für Linux oder das Handy?{{icon:chevron-down}}

Zurzeit nicht – nur für Windows und Mac.

Es klappt nicht – was nun?{{icon:chevron-down}}

Im Hilfe-Center stehen Lösungen für typische Probleme. Sonst schreib dem Team über eine Support-Anfrage.
