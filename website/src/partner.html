{{icon:sparkles}}Was Partner-Server können

Fünf Bausteine für deinen Server

Alles läuft über ein kleines Plugin auf deinem Server und den Heldix-Dienst. Spieler ohne HeldixClient merken davon nichts und spielen ganz normal weiter.

{{icon:headphones}}

Voice-Gruppen

Dein Server teilt Spieler in Gruppen ein, zum Beispiel je Team oder Runde. Wer in einer Gruppe ist, hört in der Nähe nur seine Gruppe und spricht im Gruppenkanal mit ihr – über die ganze Karte. Die Gruppen speichert der Dienst nicht; sie gelten nur, solange dein Server sie schickt.

{{icon:hud}}

Server-HUD

Bis zu acht eigene Anzeigen im Heldix-Stil: Text, Fortschrittsbalken oder kurze Listen – etwa für Punkte, Runden oder Ziele. Dazu kurze Hinweise am Bildrand. Spieler können das Server-HUD in ihren Einstellungen ausschalten.

{{icon:gift}}

Belohnungs-Cosmetics

Das Team gibt für deinen Server eigene Cosmetics frei. Dein Server schaltet sie für Spieler frei, zum Beispiel für einen Sieg oder ein Event. Im Katalog stehen sie für alle sichtbar mit „Belohnung auf“ und dem Namen deines Servers.

{{icon:shield}}

Server-Regeln

Dein Server sagt HeldixClient, welche Funktionen bei dir aus sind, zum Beispiel Freelook, Zoom, Minimap, Weltkarte, Wegpunkte, Koordinaten oder Dauersprint. Versucht ein Spieler sie zu nutzen, sieht er „Auf diesem Server deaktiviert“.

{{icon:star}}

Abzeichen „Partner“

Dein Server trägt in der Serverliste und im Pausemenü von HeldixClient das Abzeichen „Partner“ und steht auf der Webseite unter Entdecken bei den Partner-Servern. Hervorgehobene Partner stehen dort ganz oben.

So wirst du Partner

  1. Antrag stellen – unten auf dieser Seite, angemeldet mit deinem Minecraft-Konto.
  2. Das Team prüft deinen Server und meldet sich über die Kontaktangabe aus dem Antrag. Den Stand siehst du hier.
  3. Partner-Schlüssel – das Team legt deinen Server an und gibt dir einen geheimen Schlüssel für das Plugin.
  4. Plugin einrichten – Schlüssel in die config.yml eintragen, fertig. Über die Java-Schnittstelle steuern andere Plugins Voice-Gruppen, HUD, Regeln und Belohnungen.

    Fragen

    Was kostet das Partner-Programm?

    Nichts. Das Partner-Programm ist kostenlos – für deinen Server und für deine Spieler.

    Was braucht mein Server?

    Einen Paper-Server mit der Minecraft-Version von HeldixClient und das Plugin „HeldixClient Server“. Hinter Velocity oder BungeeCord funktioniert es auch: Die Proxys reichen den Kanal einfach durch, auf dem Proxy selbst brauchst du nichts. {{#serverplugin}}Das Plugin (Version {{SERVER_PLUGIN_VERSION}}, für Paper {{SERVER_PLUGIN_MINECRAFT}}) lädst du oben auf dieser Seite herunter.{{/serverplugin}}{{^serverplugin}}Das Plugin zum Herunterladen kommt bald.{{/serverplugin}}

    Was sieht mein Server von den Spielern?

    Dein Server erfährt nur, welche Spieler HeldixClient nutzen, mit welcher Version und in welcher Sprache. Voice-Gespräche hört er nicht, und die Voice-Gruppen bleiben nur im Arbeitsspeicher des Heldix-Dienstes, bis dein Server sie nicht mehr schickt.

    Was passiert mit dem Partner-Schlüssel?

    Der Schlüssel ist wie ein Passwort für deinen Server. Er erscheint nur einmal, wenn das Team ihn erzeugt – bewahre ihn sicher auf und gib ihn nicht weiter. Geht er verloren, erzeugt das Team einen neuen; der alte gilt dann nicht mehr.

    Kann das Team eine Partnerschaft beenden?

    Ja. Das Team kann einen Partner pausieren, etwa bei Missbrauch der Funktionen. Solange ist der Schlüssel gesperrt, das Abzeichen verschwindet, und der Server steht nicht mehr bei den Partner-Servern.
