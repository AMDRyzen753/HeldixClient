Bei dieser Anmeldung meldet dich der offizielle Minecraft Launcher an – gespielt wird aber mit HeldixClient, mit deinen Instanzen, Mods und Einstellungen. Sie braucht keine Freigabe von Mojang und funktioniert deshalb schon jetzt.

## Voraussetzungen
- Der offizielle Minecraft Launcher ist installiert.
- Du hast ihn mindestens einmal gestartet und dich dort mit deinem Microsoft-Konto angemeldet.

## So geht's
1. Klicke im HeldixClient-Launcher unten links auf dein Konto bzw. **Nicht angemeldet**.
2. Wähle **Über Minecraft Launcher anmelden**.
3. HeldixClient legt im offiziellen Launcher die Installation **HeldixClient** an, wählt sie aus und öffnet den Minecraft Launcher. Im HeldixClient-Launcher erscheint dazu eine kurze Anleitung.
4. Melde dich im Minecraft Launcher an, falls nötig. Unten links ist die Installation **HeldixClient** ausgewählt – drücke dort auf **Spielen**.
5. HeldixClient übernimmt die Anmeldung. In deinem Konto steht danach „Über Minecraft Launcher“.

Ab jetzt startest du wie gewohnt im HeldixClient-Launcher mit **Spielen**.

## Gut zu wissen
- **Etwa einen Tag gültig:** Eine Anmeldung hält etwa 24 Stunden. Danach öffnet HeldixClient beim Drücken auf **Spielen** wieder den Minecraft Launcher – ein Klick auf **Spielen** dort genügt, dann startet das Spiel.
- **Direkt aus dem Minecraft Launcher:** Startest du die Installation **HeldixClient** im offiziellen Launcher, startet die gerade ausgewählte HeldixClient-Instanz. Läuft HeldixClient nicht, wird es gestartet.
- **Kein zusätzlicher Download:** Die Installation baut auf einer Minecraft-Version auf, die im offiziellen Launcher schon installiert ist. HeldixClient hält sie bei jedem Start aktuell.
- **Abbrechen:** Im Anleitungsfenster bricht **Abbrechen** oder [[Esc]] das Warten ab. Drückst du 15 Minuten lang nicht auf **Spielen**, bricht HeldixClient von selbst ab.

## Sicherheit
Die Anmeldung wird nur auf deinem eigenen Rechner vom Minecraft Launcher an HeldixClient weitergereicht. Beide Seiten prüfen vorher, dass sie wirklich miteinander sprechen – ein fremdes Programm bekommt die Anmeldung nicht. Anschließend prüft HeldixClient die Anmeldung bei Mojang.

## Wenn es nicht klappt
- **„Der offizielle Minecraft Launcher wurde nicht gefunden.“** – Installiere den offiziellen Minecraft Launcher und versuche es noch einmal.
- **„… ist auf diesem PC nicht eingerichtet.“** – Starte den Minecraft Launcher einmal und melde dich dort an.
- **„Im offiziellen Minecraft Launcher ist noch keine Minecraft-Version installiert.“** – Starte dort einmal Minecraft und versuche es danach noch einmal.
- **Die Installation „HeldixClient“ fehlt im Minecraft Launcher:** War der Minecraft Launcher schon offen, schließe ihn und klicke im Anleitungsfenster auf **Launcher öffnen**.
